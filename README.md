# ⛽ Gasolina ou Alcool?
## O presente projeto trata-se de uma calculadora em tempo rel para descobrir a forma mais econômica de abastecer seu carro.
<img width="1920" height="911" alt="thumbnail" src="https://github.com/user-attachments/assets/2ce44ceb-7792-45f0-8e9a-1c54f9ae445f" />

### Funcionamento:
1- Digite o valor do litro da Gasolina
2- Digite o valor do litro do Etanol
3- Visualize no card o que compensa mais no momento
### Características:
* Desenvolvido em Next.js com abordagem Mobile-first
* Pleno funcionamento em dispositivos móveis
